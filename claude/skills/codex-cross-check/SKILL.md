# Codex 교차 검증

## 쓸 수 있는지 먼저 확인한다

1. Codex 플러그인의 `codex-companion.mjs setup --json` 을 돌린다(`~/.claude/plugins/cache/openai-codex/codex/*/scripts/` 중 최신 버전).
2. `ready` 가 `true` 일 때만 진행한다. `false` 면 건너뛰고 이유(미설치·로그인 풀림)를 알린다.
3. `ready` 가 `true` 여도 실제 호출에서 사용량·구독·인증 오류가 나면 쓸 수 없는 상태로 본다. 같은 호출을 반복하지 않는다.
4. 쓸 수 없을 때는 Codex 답을 꾸며내지 않는다. 상태, 확인한 명령, 실패 단계와 오류 요약, 이번 답에서 검증하지 못한 범위를 적고 혼자 답한다.

## 진행

1. 내 답과 근거를 먼저 파일로 고정한다.
2. Codex 에는 내 결론을 빼고 같은 자료·질문·출력 형식을 새 읽기 전용 작업(`task --fresh`)으로 보낸다. 모델은 지정하지 않는다(사용자의 Codex 설정). 사용자가 지정하면 따른다.
3. 읽어도 되는 곳과 읽지 않을 곳을 프롬프트에 적는다. 비밀값이 들어 있는 설정 파일이 그 대상이다.
4. 두 답을 항목별로 대조한다. 갈리는 곳은 양쪽 근거와 통합안을 보내 같은 대화(`--resume-last`)로 다시 묻는다.
5. 나도 Codex 의 반론을 받아 내 답을 다시 본다. 맞으면 받는다.
6. 두세 차례 안에 합의되지 않으면 억지로 합치지 않고 쟁점을 사용자 결정 사항으로 남긴다.
7. 오래 걸리는 호출은 백그라운드로 돌리고 무엇을 기다리는지 사용자에게 알린다.

## 보고

- 항목마다 소제목을 두고 차수 순서대로 기록한다. 각 차수에는 Claude 가 보낸 답·반론·통합안과 그에 대한 Codex 답을 함께 적는다.
- 마지막에 최종안과 채택 근거를 적는다. 어느 한쪽의 반론이나 변경 제안도 생략하지 않는다.
- 제안 문장은 표 칸이 아니라 인용으로 따로 낸다.
- 두 답이 처음부터 같았던 항목은 묶어서 한 줄 근거로 적어도 된다.
- 마지막 줄에 Codex 의 남은 사용량을 적는다. `python3 ~/.claude/skills/codex-cross-check/usage.py` 가 가장 최근 기록에서 5시간 창과 7일 창을 읽는다. 다음 검증을 언제 걸 수 있는지가 여기서 갈린다.
